# אזור לקוחות — משרד עורכי הדין NAHMANI-BENDAHAN

אתר מעקב ללקוחות המשרד בתביעות ביטוח לאומי.

## הפעלה

```bash
python -m http.server 8777
```
ואז לפתוח: <http://127.0.0.1:8777>

(אפשר גם לפתוח את `index.html` ישירות בדפדפן.)

## חשבונות הדגמה

| ת״ז | קוד | תרחיש |
|---|---|---|
| `123456782` | `1234` | נכות כללית — שלב 5 מתוך 8 (ועדה רפואית), 5 מסמכים חסרים |
| `987654321` | `1234` | נכות מעבודה — שלב 7 מתוך 8 (ועדת עררים) |

## מה יש באתר
- **השלב הנוכחי בתביעה** + סרגל התקדמות.
- **ציר כל 8 שלבי התביעה** — הושלם / בשלב זה כעת / ממתין, עם תאריכים.
- **הצעדים הבאים** — מה צפוי, מתי, ומה נדרש מהלקוח.
- **רובריקת מסמכים** — סינון לפי חסרים / בבדיקה / אושרו, עם **העלאה דרך האתר** (לחיצה או גרירה, PDF/JPG/PNG עד 10MB).
- **עדכונים מהמשרד** וכרטיס יצירת קשר עם הצוות המטפל.

## מבנה
```
index.html          מסך כניסה
dashboard.html      האזור האישי
assets/css/style.css
assets/js/data.js       נתונים, אחסון, אימות
assets/js/dashboard.js  רינדור ולוגיקת העלאה
```
