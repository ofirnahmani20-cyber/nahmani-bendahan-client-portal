# תמונת ה-Hero — מפרט נכס

התיקייה ריקה בכוונה. עד שתסופק תמונה, ה-Hero מציג משטח אבן
מסומן במפורש כ-placeholder. **אין להכניס לכאן תמונת stock
אקראית בלי אישור.**

## איך מחליפים

שורה אחת. הטוקן `--ds-hero-image` מוגדר ב-`assets/css/tokens.css`:

    --ds-hero-image: url('../img/hero/<שם הקובץ>');

אין צורך לגעת בשום כלל CSS אחר. גם הגובה (`--ds-hero-h`),
הכהות (`--ds-hero-overlay`) ומוקד החיתוך (`--ds-hero-position`)
נשלטים מאותו מקום.

## המפרט

| | |
|---|---|
| יחס | רחב, 3:1 ומעלה |
| רוחב | 2400px לפחות |
| פורמט | WebP מועדף, JPEG מתקבל |
| משקל | עד 400KB אחרי דחיסה |
| רישיון | חייב להתיר שימוש מסחרי |

## מה התמונה צריכה להראות

אבן ירושלמית · אדריכלות ישראלית · בטון ואבן · צמחייה
ים-תיכונית, זית וברוש · אור וצל דרמטי · קווים אדריכליים נקיים.

## מה אסור

בתי משפט אמריקאיים · עמודים קלאסיים · פטיש שופט · מאזניים ·
תמונות stock אמריקאיות · אנשים שניתן לזהות · טקסט בתוך התמונה.

## מגבלה טכנית

ה-CSP הוא `img-src 'self' data:`. התמונה **חייבת** להיות קובץ
מקומי תחת `assets/`. קישור לשרת חיצוני ייחסם בשקט.

## נגישות

התמונה דקורטיבית ואינה נושאת מידע, ולכן היא רקע ולא `<img>`
ואין לה `alt`. שכבת הכיסוי קיימת כדי שהטקסט מעליה יעמוד
בניגודיות הנדרשת; אם התמונה שתסופק בהירה, יש להעלות את
`--ds-hero-overlay` ולמדוד מחדש.
