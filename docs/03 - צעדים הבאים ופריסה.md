# צעדים הבאים ופריסה

## ⚠️ מה שהמוצר הנוכחי הוא — ומה שהוא אינו

**הוא:** MVP עובד ומלא מבחינת חוויית המשתמש — כל המסכים, הזרימות והמצבים ממומשים ונבדקו בדפדפן.

**הוא אינו:** מערכת מאובטחת לייצור. בגרסה הנוכחית:
- הסיסמאות והנתונים נמצאים ב-`data.js` — קובץ שכל אחד יכול לפתוח בדפדפן.
- הקבצים ש"מועלים" **לא נשלחים לשום מקום** — רק שם הקובץ נשמר מקומית ב-`localStorage`.

> 🚨 **אין להעלות את האתר לאינטרנט עם נתוני לקוחות אמיתיים לפני השלמת שלב 1 להלן.** מדובר במידע רפואי ומשפטי — חלה עליו חובת סודיות מקצועית וחוק הגנת הפרטיות.

## שלב 1 — Backend (חובה לפני עלייה לאוויר)

| נדרש | פירוט |
|---|---|
| שרת + מסד נתונים | טבלאות: `clients`, `cases`, `case_stages`, `documents`, `messages` |
| אימות | סיסמאות ב-hash (bcrypt/argon2), session cookie מסוג `HttpOnly` + `Secure`, הגבלת ניסיונות כניסה |
| אימות דו-שלבי | קוד SMS חד-פעמי — מומלץ מאוד למידע רפואי |
| העלאת קבצים אמיתית | `multipart/form-data` לשרת, סריקת וירוסים, אחסון מוצפן, הרשאות לפי לקוח בלבד |
| HTTPS | חובה. כולל HSTS |
| תיעוד גישה (audit log) | מי צפה ומתי — נדרש להתמודדות עם טענות בעתיד |

### נקודות ההחלפה בקוד
```js
// data.js — Auth.login()
const r = await fetch('/api/login', {
  method: 'POST',
  headers: {'Content-Type':'application/json'},
  body: JSON.stringify({ idNumber, password })
});

// data.js — CaseStore.load()
const r = await fetch('/api/my-case');   // השרת מזהה את הלקוח מה-session

// dashboard.js — handleFile()
const fd = new FormData();
fd.append('file', file);
fd.append('docId', docId);
await fetch('/api/documents/upload', { method: 'POST', body: fd });
```

## שלב 2 — ממשק ניהול למשרד
מסך פנימי שבו הצוות מעדכן שלב בתיק, מאשר/דוחה מסמכים שהועלו, ושולח הודעות ללקוח. כרגע כל אלה מוזנים ידנית ב-`data.js`.

## שלב 3 — שיפורים מומלצים
- התראות SMS/מייל אוטומטיות כשהשלב משתנה או כשמסמך אושר.
- הורדת המסמכים שהועלו בחזרה (כרגע רק העלאה).
- תצוגת סיבת דחייה כשמסמך נדחה ("הצילום לא קריא").
- תמיכה בערבית ורוסית — התשתית כבר בנויה נכון לכך (`inset-inline`, אין `left/right` קשיחים).
- נגישות: בדיקת תקן ת"י 5568 / WCAG 2.0 AA — חובה חוקית לאתר שירות בישראל.
